# examples/ —— 合成样例数据（假数据，禁止写进论文）

本目录是 ec-lab 仓库内置的**合成样例数据**，由 `make_mock.py --sample` 生成。
它不是任何真实样品的测量结果，所有比电容、阻抗数值都是**人为设定**的，
用途只有两个：

1. **回归测试锁定计算公式**——regress_check.py 的「合成档」跑的就是这套
   数据，任何机器（包括没有真实数据的 CI）都能验证公式没被改坏；
2. **新人上手**——clone 仓库后把数据目录选到 `examples/sample_data`，
   立刻能跑通「选文件夹 → 开始处理 → 预览确认输出」三步。

## 数据内容（质量统一登记 1.0 mg）

| 文件 | 类型 | 条件 | 设定比电容 | 回归锁定值 |
|---|---|---|---|---|
| `CV/cv-2mVs.txt` | CV | 2 mV/s | ≈107.1 F/g | 106.8 |
| `CV/cv-5mVs.txt` | CV | 5 mV/s | ≈82.4 F/g | 82.2 |
| `CV/cv-10mVs.txt` | CV | 10 mV/s | ≈70.0 F/g | 69.7 |
| `CV/cv-20mVs.txt` | CV | 20 mV/s | ≈61.2 F/g | 61.0 |
| `GCD/gcd-1Ag.txt` | GCD | 1 A/g | 95.0 F/g | 95.0 |
| `GCD/gcd-2Ag.txt` | GCD | 2 A/g | 78.0 F/g | 78.0 |
| `EIS/eis-1.txt` | EIS | 0.35 V 直流偏压 | Rs≈5 Ω + Rp≈30 Ω 容抗弧 | — |

CV 的设定真值公式：`C(v) = 40 + 3/√v`（v 单位 V/s）——纯电容部分不随
扫速变，法拉第部分随扫速单调下降，所以表观比电容随扫速单调下降
（铁律 #4）。GCD 两个电流密度下也都单调下降。

实测比设定值低约 0.3%（CV）的原因：取数段的首点差一个采样步长，积分
窗口比名义电位窗口略窄，梯形积分对峰形也有离散误差——**真实 CHI 数据
是完全一样的性质**（真实文件的段跨度就是 1.599 V 而不是 1.600 V）。
回归锁定的是引擎对固定文件的实测值，不是设定值。

## 文件格式

与 CHI660F 导出一致：UTF-8 编码、逗号分隔、表头字段齐全
（`Scan Rate (V/s)`、`Cathodic Current (A)`、`Segment` 等），
`parse_cv` / `parse_gcd` / `parse_eis` 可直接读取。每个 CV/GCD 文件都是
4 段结构（第 1 段活化、第 2+3 段稳定被采用、第 4 段没测完），
和真实数据的段落行为一致。

## 重新生成

```
python make_mock.py --sample
```

质量登记在 `make_mock.py` 的 `sample_mass_table()` 里**逐个显式登记**
（统一 1.0 mg），没有 `*` 兜底——未登记质量就跳过，这是铁律 #2。
改了我的生成参数后，记得重跑 `python regress_check.py` 核对锁定值。
