# 从实验数据到 Excel 和科研图

源码版从项目目录的 `启动软件.bat` 启动（首次按 README 生成启动器），便携版双击 `ec-lab.exe`。日常使用只需要两个部分：**数据处理**负责读原始文件、计算并保存 Excel；**一键绘图**负责读 Excel、选图和导出图片。两个部分可以分开使用。

本次功能使用项目现有的 Python、PySide6、pandas、openpyxl 和 Matplotlib，无新增依赖，也不用联网才能画图。

## 2026-10-24：默认沿用原 Excel

“开始处理”现在进入原脚本 Excel 流程；“电导率处理”默认生成 CDI 七表。详细步骤见 [沿用原 Excel 的说明](original-excel-guide.md)。下文的标准长表处理仍可从“比电容 / EIS 计算”和“仅整理电导率与单位”进入。

## 先试一次，不需要自己的实验参数

1. 打开软件，点击工具栏的 **电导率处理**，再点 **仅整理电导率与单位…**。
2. 点击 **添加文件…**，选项目或便携包内的 `examples/conductivity_demo.csv`。这是明确标记的合成演示数据，不能当作实验结果。
3. 保持电导率单位“自动识别”，点击 **读取并检查**。应显示 7 行、7 个有效点、0 条错误。
4. 点击 **导出并一键绘图**。程序先生成标准 Excel，再打开绘图工作台。
5. 在“常用图”中选择电导率图，选一个样式，预览满意后导出。输出路径会显示在窗口中。

## 处理电化学数据

1. 在主界面点击 **添加文件夹**，选择实际要分析的一组电化学实验数据，建议按样品选择子文件夹。
2. 扫描文件，检查样品、文件勾选、质量和其他计算参数。质量必须符合这次真实实验，不能为了得到预期数字而修改。
3. 点击 **开始处理**，再点 **比电容 / EIS 计算…**。程序计算并保存 Excel，完成后日志会给出文件位置。输出文件夹应放在项目的 `output` 下，不能选原始实验数据文件夹。
4. 点击 **Excel 一键绘图**，打开刚生成的 Excel。在“常用图”中选择识别出的 CV、GCD、EIS 等图形，再选择样式、预览和导出。列表内容取决于工作簿实际包含的数据。
5. 如果想调整旧版的详细电化学绘图参数，也可以继续用主界面的 **预览图形**。

更改质量或计算参数后，要重新点击“开始处理”生成新的 Excel；只改颜色、字体等外观时，可以直接在绘图工作台调整。

## 处理电导率数据

1. 点击 **电导率处理**，用 **添加文件…** 选择一个或多个 `.xlsx`、`.csv`、`.txt`、`.tsv` 文件。旧版 `.xls` 需要先另外保存为 `.xlsx`。
2. DDSJ 导出的 Excel 通常包含“测量时间”“检测结果”，比如 `1002uS/cm`。这类文件可直接自动识别，列顺序不同也可以。
3. 如果原始值只有 `1002` 这样的数字，必须明确选择它的真实单位。可选 `μS/cm`、`mS/cm`、`S/m`。不清楚单位时，先查仪器导出记录；程序会报告缺单位，不会擅自猜测。文件单元格中的单位优先于列标题单位，列标题单位优先于下拉选择。
4. 数字时间没有明确单位时，在 **无单位数字时间** 中选择秒、分钟或小时。日期时间如 `2026-07-04 21:10:53` 会自动转为相对时间；首个可解析时间作为零点。
5. 点击 **读取并检查**。查看有效点数和下面的错误清单。预览只显示前 30 行，导出包含全部导入行。错误清单较长时，窗口显示前 300 条，Excel 中保留全部。
6. 点击 **导出标准 Excel** 或 **导出并一键绘图**。默认生成新的 `output\conductivity_日期时间_随机后缀\conductivity.xlsx`，不会覆盖之前的结果。

每批最多处理 10 万个测量行、每张输入表最多 64 列；超过限制会明确报告，需要拆成几批选择文件。程序串行读取文件，读写完成前不允许关闭当前处理窗口，避免中断写文件。

导出的 `conductivity` 工作表包含这些关键列：

| 列名 | 含义 |
| --- | --- |
| `file` | 曲线分组；区分源文件和工作表 |
| `elapsed_s` | 相对于本表首个有效时间的秒数 |
| `conductivity_uS_cm` | 统一为 μS/cm 的电导率 |
| `source_path`、`source_sheet`、`source_row` | 原始文件、工作表和 Excel/文本行号 |
| `raw_time`、`raw_conductivity`、其他 `raw_*` | 原始读值，供追溯检查 |
| `status` | 该行解析状态；`ok` 表示没有数值解析错误 |

`issues` 保存缺失值、坏值、缺单位、时间重复或倒退等问题；`sources` 保存来源和本次解释规则；“说明”记录单位换算及处理范围。空白或无法解析的测量行仍然保留，对应标准数值留空。时间顺序不会自动排序、去重、补点或平滑。

标准整理入口只处理电导率与时间。需要浓度、吸附容量和速率时，在 CDI 七表入口核对历史标定参数、体积、质量后生成；详见原 Excel 说明。

## 自己的 Excel 也能画图

点击主界面的 **Excel 一键绘图**，打开自己的 Excel 或 CSV。如果“常用图”不能自动识别，就到手动选列页选择工作表、X 数值列和 Y 数值列。多个 Y 列画在同一坐标轴上时，应当使用相同单位。检查坐标轴标题及单位后再导出。

工作台中的科研样式是字体、线宽、配色等**外观预设**，不是期刊认证，也不能替代投稿指南。已有图形的计算方法、轴单位和实验条件仍需要研究者审核。

## 原始文件和输出到哪里

- `E:\Data` 只读，不新增、删除或修改原始实验文件；新功能也禁止向源文件夹及其子文件夹输出。
- 新结果默认位于软件目录内的 `output`。文件夹名称和窗口显示的路径是找回结果的依据。
- 原始 Excel / CSV 请放在独立的数据文件夹中，不要直接放到 `ec-lab.exe` 旁边；否则默认 `output` 位于源目录内，输入保护会拒绝导出。包内的 `examples` 子文件夹可直接用于演示。
- 绘图配方记录源表格的完整路径。搬到另一台电脑后，先重新打开随包拷过去的 Excel 并出图，再保存新配方。
- 源工作簿中的公式按文件已有缓存值读取；如果没有缓存，会作为缺失值提示。程序不启动 Excel 去刷新原始工作簿。
- “时间重复或倒退”表示源数据里存在这种顺序，可能是实验重启、跨午夜或复制拼接；先检查来源，不要直接把提示当作可以忽略的噪声。
- 同一工作簿内的浓度、吸附容量等其他汇总表若没有可识别的时间和电导率列，会明确记录为未导入；不会当成原始电导率曲线。
- 不需要关闭向日葵远程控制。出现问题时，保留窗口中的报错及输出文件路径，方便定位。
