# ec-lab 双工作区界面说明（2026-10-24）

用户最终选择了 **双工作区：数据处理 / 一键绘图**，以及 **左侧固定文件清单、参数按需展开** 的排版。正式界面已按这个选择接入现有处理与绘图功能；本文件记录实际使用方式。

## 主界面与页面关系

顶部标签切换两个常驻工作区。切换页面保留当前文件、结果和图的设置，不重新创建处理窗口。旧版详细电化学界面保留为高级入口，从 **帮助 → 高级电化学工具 → 打开高级工作区** 进入；通过 **返回数据处理** 回到双工作区。

| 区域 | 数据处理 | 一键绘图 |
|---|---|---|
| 左侧 | 固定文件清单；添加文件、添加文件夹、移除选中、清空列表 | 常用图列表；也可切到按列绘图，选择工作表和 X/Y 列 |
| 右侧上方 | 处理类型、用途提示、关键参数摘要、质量识别来源 | 当前预览、更新预览、绘图设置 |
| 详细设置 | 默认收起；展开参数或修改质量后编辑 | 默认收起；按坐标轴、图例与颜色、字体与尺寸分组 |
| 执行与结果 | 开始处理并生成 Excel、处理进度、结果文件、用这份 Excel 一键绘图 | 大图预览、输出当前图、选择图片输出、打开结果 |

数据处理清单中的文件都会参与本批处理，移除或清空只改变清单。悬停文件名可查看完整路径。添加文件夹按当前处理类型递归扫描，每批最多 100 个，跳过明显的已处理 Excel；扫描在后台运行。

## 五个菜单

| 菜单 | 已提供的入口 |
|---|---|
| 文件 | 添加文件夹、输出位置、结果文件夹、退出 |
| 处理 | 加载数据处理模板、保存数据处理模板、修改数据处理模板 |
| 绘图 | 绘图模板 → 加载模板 / 编辑模板；绘图设置；调色盘 |
| 外观 | 浅色模式、深色模式 |
| 帮助 | 使用说明、科研绘图设计学习报告、高级电化学工具、查看错误日志、关于 ec-lab |

文件菜单的输出位置用于两个工作区；结果文件夹优先打开最近一次输出所在目录。浅色、深色切换只改变软件外观，科研图画布和导出背景保持白色。

高级电化学工具子菜单还保留原绘图模板与详细设置、原数据处理模板加载和保存。比电容、EIS、旧长表汇总及原来的详细预览继续从这里使用。

## 数据处理的日常路径

1. 选择处理类型，再添加本批文件或文件夹。
2. 核对常显摘要。需要时展开参数；选好保存位置。
3. 点 **开始处理并生成 Excel**。进度和具体结果路径显示在右侧。
4. 在底部选择结果文件，点 **用这份 Excel 一键绘图**，切到已有的绘图工作区。

CDI 默认 **50 mL**，采样间隔默认 **从原始时间自动识别**。无法识别有效时间时，需要展开参数改为手动填写秒/点。每圈时长、体积和标定参数都可修改。

质量先从明确的文件名或所在文件夹填入建议值，并显示来源。例如 `FTO@C1(25mg)-200mg.xlsx` 建议 25 mg；用户可以修改。文件有不同质量时提示分批，手填一个数值也不会取消混合质量保护。无法确定质量时留空并要求填写；更换文件不会静默沿用上一批质量。计算始终使用界面显示的本次质量。

加载计算库、读取数据和写 Excel 在后台执行，打开处理页不先加载整套计算依赖。任务期间仍可查看已有页面；结束并清理线程前不允许关闭主窗口或启动第二个重任务。

## 三类模板与记录

| 类型 | 保存内容 | 使用方法 |
|---|---|---|
| 数据处理模板 | 处理类型及适用的质量、体积、采样、标定等参数 | 处理菜单加载和保存；修改入口展开当前参数，改好后再保存 |
| 绘图样式模板 | 坐标范围、图例、配色、字体、尺寸等外观 | 绘图模板菜单加载和编辑；在设置区点保存样式模板 |
| 绘图配方 | 本次源文件、校验值及每张图的配置 | 绘图页点恢复绘图配方，校验源文件后恢复 |

数据处理模板带有 `schema/version/mode/parameters`，加载时校验格式、参数和范围，不含输入文件列表、输出位置或 CDI 格式模板路径。已有文件时，模板质量不覆盖本次确认值。参数模板和样式模板用于复用设置，绘图配方用于重现一次具体绘图。

打开数据后加载绘图样式模板会应用到当前图，其他图保留自身设置；也可以先加载样式模板再打开数据。

## 绘图与输出

打开处理后的 Excel，软件自动列出能识别的常用图；通用表格可使用 **按列绘图**。主要在上方 **当前预览** 切换待调整的图，左侧图列表与它同步。**正在调的图** 仅显示名称。图名不附加曲线条数。

**绘图设置** 可修改图片名称、图内标题、X/Y 轴标题及范围、图例显隐与位置、逐曲线图例名称、整组配色与逐曲线颜色、字体和字号、厘米尺寸、线宽和 DPI。输入有效设置后点 **更新预览**；切图保留当前图已填写的有效修改。菜单的 **调色盘** 用于选择整组配色。

点 **输出当前图** 或 **选择图片输出** 后，先弹出选图窗口：全选、全不选、逐图勾选、逐图命名、选择 PNG/PDF/SVG 和保存位置。至少选一张图及一种格式才能输出；取消不写图片。同名文件保留旧文件并为新文件增加后缀。完成后询问是否打开保存位置，默认不打开。
