# 沿用原 Excel 的数据处理与绘图

2026-10-24 版采用顶部 **数据处理 / 一键绘图** 两个工作区。数据处理页左侧固定显示本批文件清单，右侧显示处理类型和关键参数摘要，详细参数默认收起。切换工作区会保留当前文件、结果和绘图设置。

用户提供的四份原脚本副本位于 `legacy_processors`，内容保持不变；适配层负责选文件、检查参数和写入独立结果目录，不调用会在原目录输出的 `main()`。

## 日常使用

1. 打开 **数据处理** 工作区，先选处理类型：CV/GCD、CP 循环、CV 循环、CDI 电导率或电容贡献率。
2. 在左侧 **添加文件**，或用 **文件 → 添加文件夹** 递归添加本类型的文件。清单中的文件都参与本批处理；“移除选中”“清空列表”只改清单，不删除硬盘文件。每批最多 100 个，添加文件夹时跳过明显的已处理 Excel。
3. 核对右侧常显摘要。CDI 显示本次质量、体积和采样方式；点 **修改质量** 可直接定位质量框，点 **展开参数** 查看全部参数。同一样品、同一质量分批处理。
4. 用 **文件 → 输出位置** 或页内保存位置选择独立结果目录，点击 **开始处理并生成 Excel**。进度在右侧显示。
5. 完成后，在底部 **结果文件** 中选择工作簿，点 **用这份 Excel 一键绘图**，进入已有的一键绘图页。也可直接切换上方标签，点 **打开 Excel / CSV** 打开已有结果。
6. 需要单纯整理电导率单位时，在 CDI 类型下点 **仅整理电导率与单位**。比电容、EIS 拟合、旧长表汇总和详细预览从 **帮助 → 高级电化学工具 → 打开高级工作区** 进入。

## 保存和复用模板

**数据处理模板** 是参数 JSON，包含处理类型、质量、采样方式、体积、标定等适用参数，不包含本批文件列表、输出位置或 CDI Excel 格式模板路径。加载前校验格式版本、数值范围和参数；不会执行模板中的代码。

先调整参数，再用 **处理 → 保存数据处理模板** 保存。下次用 **加载数据处理模板** 恢复；**修改数据处理模板** 会展开当前参数，修改后再次保存。已有文件时，模板中的质量不会覆盖当前文件的质量确认值，加载后仍需核对常显的本次质量。

**绘图样式模板** 保存坐标范围、图例、配色、字体、尺寸等样式，可用于另一份数据。用 **绘图 → 绘图模板 → 编辑模板** 展开设置，修改后点击设置区的 **保存样式模板**。若在打开数据后加载样式模板，它应用到当前图；其他图保留各自样式。

**绘图配方** 用于恢复某次绘图的数据来源和设置，会校验原文件。通过绘图页的 **恢复绘图配方** 打开，和可用于新样品的样式模板区分使用。

## 保持的 Excel 布局

| 类型 | 原来的布局与计算口径 |
|---|---|
| CV结果.xlsx | `Potential` 加各扫速列，电流除以本批质量，单位 A/g；原脚本自动选第 2+3 或 3+4 段 |
| GCD结果.xlsx | `GCD_Data`、`Duration`；固定间隔 Time 列、多列电压，保留黄色峰值 |
| CP 循环 | `全量CP数据`、`放电时间汇总`、存在数据的 `尾数0圈`～`尾数9圈` |
| CV 循环 | `原始处理数据`、`尾号0`～`尾号9`；第一圈电压作公共 X，电流保留原始 A |
| CDI | `原始数据`、`电导率`、`浓度`、`浓度差`、`吸附容量`、`吸附速率`、`吸附最大值` |
| 电容贡献率 | `数据栏`、`处理栏`、`结果栏`、`结果`；保留原字体、数字格式、合并单元格、共享公式（仅加宽结果页列宽以避免数字遮挡）、SLOPE/INTERCEPT 和有符号梯形积分 |

每次在选择的保存位置下生成独立结果文件夹；参数、来源路径和 SHA256 另存为 `处理说明.json`，不会为了放说明而重排 Excel。

## CDI 参数与小修正

采样间隔默认从原始时间自动识别，缺少时间时可切到手动填写。质量从文件名或最近的文件夹识别并显示，允许修改；本批存在不同质量时提示分批，无法识别时必须手填，不沿用上一批质量。默认保留 60 分钟/圈、标定截距 8.2236、斜率 1.97252。体积在界面明确使用 **mL**，默认 **50 mL**，代入旧公式时换算为 **0.05 L**。用户已于 2026-10-24 确认常用体积为 50 mL。其余参数与每次实验仍需核对。

电导率统一为 μS/cm；浓度按 `(电导率 − 截距) / 斜率`，浓度差仍以各圈起点为基准。吸附容量保留 `浓度差 × 体积(L) / 质量(mg) × 1000`，单位 mg/g。吸附速率保持原来的平均速率，时间分母是秒，单位 mg/g/s，未擅自改为瞬时速率。

只对两个明确的空值问题加保护：零秒的速率留空；末圈补齐位置在后续计算中继续留空，不将缺测当成零电导率。有效点保留原公式。公式旁的数值缓存也同步保存，因此无需先启动 Excel 重算即可绘图。用户在 Excel 修改输入后仍应重算并保存。

时间戳允许不超过 1 秒或采样间隔 2% 的轻微累计抖动，实测时间原样保留。明显不规则时间、不完整测量值、混合工作表会停止 CDI 分圈计算，避免按错误圈长生成吸附结果；可先使用标准电导率整理入口检查。

与两组用户参考 Excel 全量对照后，七表保持宋体 11 号，计算公式和有效值一致（仅存在浮点舍入差）。完整循环末端恰好多出的一个边界点保留在原始表，不生成只有一个点的新圈；一般不完整末圈仍保留已有点。原始表中用户手工添加的温度文字、最大值表的手动黄色标记不作为自动计算规则。具体见 [CDI 核对记录](cdi-reference-audit-20261024.md)。

切到 CDI 类型不再同步加载计算库；点击开始处理后，依赖加载与计算在单个后台任务中进行，界面显示进度且可继续响应。文件夹扫描也在后台执行。任务完成并清理线程前，不允许关闭正在处理的页面或主窗口。

## 原脚本计算边界

- **CP 放电时间需要复核**：原 `calc_discharge_time` 对负电压寻找峰，实际候选位置是电压谷点，与注释“最高点到谷点”不一致。此版本为了保持旧结果没有替换该算法，界面和处理日志明确提示；曲线、分圈及尾数分表可继续对照使用。请勿把该汇总直接作为已经核实的放电时长。
- GCD 和 CP 的 Time 列仍按设定采样间隔生成。GCD 的 Duration 保留原脚本的峰谷索引及实测时间差。
- CV 各文件电压长度或网格不一致时停止合表；不自动插值。重复条件名停止处理，避免旧脚本悄悄覆盖列。小数条件名完整保留。
- CV 循环仍使用首圈电压列。发现各圈网格不同会明确提示，不静默重新采样。
- 电容贡献率模板固定为 3201 点、−0.8→0.8→−0.8 V、0.001 V 步长，以及 2、5、10、20、50、100、200 mV/s。网格不符时停止填表；不擅自改变模板公式或实验数据。输出百分比不会裁切到 0–100。
- 包内贡献率模板已清空原材料测量电流和公式缓存，保留电压网格、扫速、公式与格式。原来桌面上的模板没有修改；原模板实验数据没有打进便携包。

## 一键绘图与图片输出

打开 Excel 后，左侧 **常用图** 自动列出能识别的图；也可以切到 **按列绘图**，选工作表、X 列、一个或多个同单位的 Y 列及分组。第一行为列名，空值保留为断点。

上方 **当前预览** 切换要调整的图；设置中的 **正在调的图** 只显示名称。点击 **绘图设置** 展开坐标轴、图例与颜色、字体与尺寸：可改图片名称、图内标题、轴标题与范围、图例名称及位置、整组或逐曲线颜色、字号、厘米尺寸、线宽和 DPI。改完点 **更新预览**；切图会保留当前图已填写的有效设置。图名不附加“（6 条）”等计数。

点击 **输出当前图** 或 **选择图片输出**，在弹窗中勾选图片、逐图改名，选择 PNG/PDF/SVG 和保存位置。支持全选、全不选和取消；至少选择一张图及一种格式才能输出。取消不写图片，同名图片会增加后缀而保留旧文件。完成后询问是否打开保存位置，默认不打开。

## 高级电化学预览

在 **帮助 → 高级电化学工具** 打开旧工作区后，**预览图形** 会自动准备当前勾选文件的数据，不要求先生成 Excel。右侧 **正在调的图** 只显示名称，切图在上方 **当前预览**、上一张、下一张完成。改样式后点 **重新绘制**，点 **保存参数** 保留高级预览设置。

已修复滚动容器初始为零尺寸导致整张预览被裁掉的问题。预览按比例显示整张图，放大、缩小和鼠标框选使用同一坐标换算；显示缩放不会改变导出图片的物理尺寸。自动检查同时验证实际画面与导出结果。

高级工作区的 **直接输出** 也使用选图弹窗和完成后的打开位置提示。

## 验证与资源限制

四份原脚本的 SHA256 与用户提供文件一致。合成输入逐单元格、逐格式对照 CV/GCD、CP、CV 循环结果；贡献率模板保留公式和样式，使用原模板现有数值核对计算缓存，最大数值差约 1.6×10⁻¹³。CDI 检查单位换算、零秒、末圈缺测及缓存；真实 FTO 数据仅只读验证。

使用单个后台任务。每批最多 100 个文件、单文件 50 MB；CP/CV 循环宽表限制 50 万单元格、CDI 七表限制 100 万单元格；单图最多 200 条曲线，超过时使用尾号分表或手动选择列。源目录及 `E:\Data` 禁止写入。向日葵无需关闭。
