# 独立绘图工作台：来源与使用约定

`ec_plotting.py` 使用现有 Matplotlib 的 Figure API 绘图，不调用外部应用、不需要联网或安装 LaTeX。`ec_plot_studio.py` 是原生 PySide6 界面。

- [Matplotlib 官方样式文档](https://matplotlib.org/stable/users/explain/customizing.html)：参考字体、刻度、配色和图幅的常规设置方式。
- [SciencePlots](https://github.com/garrettj403/SciencePlots)（MIT）：参考科研图的内向刻度、简洁边框、单色印刷和展示尺寸等设计思路。工作台的三个模板由本项目实现；没有复制 SciencePlots 源码，没有安装该依赖，也不宣称已符合某家期刊的投稿规范。

论文简洁、黑白印刷、报告展示三种模板只改变外观；不会改变测量值，不排序、不平滑、不插值、不截断采样点。EIS Nyquist 图按列约定使用 `-Z_im_ohm`，并对拟合曲线使用同样符号约定。

Excel 公式只读取文件中已经保存的数值缓存。修改公式后，请先在 Excel 中重算并保存。完全空白的行与数值空缺保留为线条断点。选择非数值列会明确报错。超过 20 条曲线时省略图例，并在界面提示；数据仍全部保留。

输入支持 `.xlsx`、`.xlsm`、`.csv`、`.tsv`。每文件最多 50 MB，每表最多 10 万行、500 列，整本最多 100 万单元格，Excel 解压后最多 200 MB，每图最多 200 条曲线，一次最多输出 64 张图。超限时停止并提示拆分，不静默截断。工作台只缓存当前一张低 dpi 预览，导入与批量导出使用单个后台任务。

每次导出前先核对源表格 SHA256；导入后被修改的文件必须重新导入。随后创建项目 `output/绘图_时间_唯一编号/`，不会覆盖输入或以前的结果。PNG 为 600 dpi，PDF/SVG 为矢量格式。结果目录包含 `绘图配方.json`，记录源文件路径与 SHA256、工作表、X/Y 列、分组、EIS 符号转换、模板、轴标题及格式。打开配方会先验证源文件未改变，并恢复旧版工作簿的条件列映射。请保留源表格；如果移动了源文件，当前版本请重新导入新路径再生成配方。

CV/GCD 汇总表出现重复扫速或电流密度时，自动比电容图使用散点并显示提示；没有材料分组信息时，不会把多个材料误连为一条倍率曲线。

电导率采用处理模块明确提供的 `conductivity_uS_cm`（μS/cm）列；有有效 `elapsed_s` 时使用秒作为 X 轴，否则可使用 `source_row` 并标明它是源数据行号，不推测时间或测量单位。旧版 ec-lab 工作簿的 CV/GCD 扫速、电流密度可从 `summary.condition` 读取，仍然只用于绘图，不重新计算实验结果。
